# rangpur-geospatial-environmental-analysis
Geospatial Environmental Analysis of Rangpur Using Elevation, Water and Vegetation Indices

# Project Description
This project presents a geospatial environmental analysis of Rangpur by integrating DEM (elevation), NDWI (water), and NDVI (vegetation) satellite raster datasets. Using Python and Rasterio, the workflow aligns multi-source spatial data to a common spatial reference and valid-pixel footprint. Through percentile-based classification and approximately 1 km grid-level evaluation, the study identifies low-elevation and high-moisture zones, producing statistical summaries, spatial visualizations, and structured CSV outputs.

# Key Highlights
Raster Data Integration: Integrated DEM, NDWI, and NDVI raster datasets using Python and Rasterio, establishing a common spatial reference and valid-pixel footprint.

Environmental Index Analysis: Conducted elevation, water-index, and vegetation-index analysis using NumPy and Pandas to investigate spatial environmental variations across Rangpur.

Percentile-Based Spatial Classification: Developed percentile-based spatial classification to identify areas characterized by relatively low elevation and higher NDWI values.

Grid-Level Analysis & Outputs: Performed approximately 1 km grid-based environmental analysis, generating statistical summaries, spatial visualizations, and structured CSV outputs.
